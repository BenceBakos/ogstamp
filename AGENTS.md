# OG Stamp MCP Server

Homepage: https://ogstamp.com

Remote Streamable HTTP MCP at https://ogstamp.com/mcp

## Tools

- render_og_image — build a 1200x630 Open Graph PNG URL
- og_pricing — list forever-credit packs

## Install

Add to your MCP client:

```json
{ "mcpServers": { "ogstamp": { "url": "https://ogstamp.com/mcp" } } }
```

No local process. No API key required for light free use.
